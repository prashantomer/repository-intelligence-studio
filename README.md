# Engineering Knowledge Assistant

Rails monolith for repository ingestion, code intelligence, semantic retrieval, and AI-assisted engineering workflows.

## Current foundation

- Ruby `3.3.4`
- Rails `8.1.3`
- PostgreSQL
- Redis
- Sidekiq
- Hotwire
- RSpec
- pgvector

## Local setup status

The application scaffold, base gem stack, and foundation runtime configuration are in place.
Domain features, database schema, and ingestion workflows are not implemented yet.
